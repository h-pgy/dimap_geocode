# Leaflet-Geoman Modes Documentation

## Overview

"Leaflet-Geoman has different modes. Only one mode can be active at a time. Enable them to let your users create and manipulate layers on the map."

Users can activate modes through programmatic control, the toolbar interface, or custom implementations.

## Available Modes

### Available Modes
- **Draw Mode** - Create new geometric shapes on the map
- **Edit Mode** - Modify existing layers and geometries
- **Drag Mode** - Move layers across the map
- **Removal Mode** - Delete unwanted layers
- **Cut Mode** - Separate portions of geometries
- **Rotation Mode** - Rotate layers at any angle

## Additional Features

The library also supports:
- Text layers for adding labels
- Layer groups for organization
- Customization options
- Utility functions
- Keyboard shortcuts
- Lazy loading capabilities
