# Leaflet-Geoman Documentation - Introduction

## Overview

Leaflet-Geoman is a plugin that enables users to "Draw, Edit, Drag, Cut, Rotate, Split, Scale, Measure, Snap and Pin Layers" within Leaflet maps.

## Supported Geometry Types

The tool works with:
- Markers
- CircleMarkers
- Polylines
- Polygons
- Circles
- Rectangles
- ImageOverlays
- LayerGroups
- GeoJSON
- MultiLineStrings
- MultiPolygons
