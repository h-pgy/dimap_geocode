Ícones das ações e menu

As camadas aparecem separadas antes da tela montada: o que se aprova é a peça reutilizável, não o arranjo dela.

1 · Tokens

Nenhum token novo. As peças desta SPEC compõem escalas, materiais e tipografia que já existem. Se o desenho pedisse cor ou sombra nova, o sinal seria de peça errada — não de token faltando.

3 · Moléculas

Duas formas do mesmo item, e quem escolhe entre elas é o menu: .item-menu é a linha compacta, para menu estreito; .card-acao é o cartão explicativo, que traz para a superfície o texto que na linha só existe como tooltip. As duas leem o mesmo contrato de ação.
